Agent 编排器：用显式状态机管理 SCOPE → DISCOVER → BASELINE → DRILLDOWN → CORRELATE → VERIFY → REPORT，并设置查询次数、时间、成本和停止条件。
事实由完整查询或确定性计算直接支持
推断附支持证据、反证与置信度
建议动作预览风险；写操作审批后执行并验证
1. 定界确认服务、环境、时间窗与访问范围
2. 发现读取 Project、LogStore、索引与字段类型
3. 基线判断是否真异常并定位拐点
4. 下钻按版本、Pod、错误码、接口找贡献维度
5. 关联串联上下文、Trace、发布与配置变更
6. 验证比较正常组并主动寻找反证
7. 报告结论、证据、缺口、建议与复跑入口
硬门槛：结果不完整、字段不存在、时间窗过大、权限不足或证据冲突时，Agent 必须缩窗、换策略、降置信度或请人确认，不能直接下根因结论。

第 1 周

底座：字段规范、资源目录、RAM / STS、历史事故样本

退出条件：能准确解析服务到 LogStore

第 2 周

工具：复用官方 Query Skill / MCP，增加 QuerySpec 校验网关

退出条件：所有查询只读、限时、限量、可审计

第 3–4 周

诊断：四类固定工作流、基线对比、证据引用、模型报告

退出条件：历史事故 Top-3 候选可评测

第 5–6 周

上线：越权与注入测试、失败恢复、只读灰度、反馈闭环

退出条件：无越权、无无证据强结论

证据链回答指标：关键结论证据覆盖率 100%，支持一键复跑
Schema-aware 查询编译器指标：字段幻觉拦截率、查询一次成功率、扫描量下降
发布前后 + 对照组验证指标：Top-3 根因命中率、错误归因率、MTTI
日志质量医生指标：缺失 Trace ID、字段漂移、未建索引问题关闭率
