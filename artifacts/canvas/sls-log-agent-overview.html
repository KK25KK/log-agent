Eino 负责

  • 对话理解和有限工具选择
  • 确定性 Workflow / Graph
  • Tool Schema、Callback、短期中断恢复

自有 Go 层负责

  • 权限、云凭证和查询预算
  • 任务可靠性、证据与审计
  • 飞书会话、幂等与消息投递
建议采用 Eino v0.9.14 隔离在编排适配层；暂不使用 v0.10 alpha。
采用项用途生产约束
ADK ChatModelAgent + Runner意图理解、有限工具选择只开放受控 Graph Tool
Compose Workflow / Graph固定调查步骤与反证循环节点可测试、可重放
Typed Tool / GraphToolSLS、发布、Trace 能力参数先过 Schema、ACL 和预算
Callback模型、Tool、Graph 观测转换为稳定业务事件
Interrupt / Checkpoint补充输入和短期恢复不能替代业务数据库

第一版使用

  • 单 Agent
  • 固定错误突增 Graph
  • 强类型 Tool 和 Callback

第一版暂缓

  • DeepAgent、Supervisor、多 Agent
